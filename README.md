# Wesley Huang — Personal Website

A responsive, static portfolio prepared for GitHub Pages.

## Preview locally

Open `index.html` directly in a browser, or serve this directory with any static file server.

## Deploy

Copy `index.html`, `styles.css`, and `script.js` to the root of the `huangwesley.github.io` repository, commit, and push to `main`. GitHub Pages should publish the update automatically.
